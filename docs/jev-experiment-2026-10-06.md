# Jev HS 후보 판단 비교 실험

2026-10-06 실제 API 호출 결과. **관세 후보 선택의 처리시간을 약 5~6배 줄였고 비용도 낮아졌다. 품질은 데이터와 보류 기준에 따라 달랐다.** 전체 URL 수집·포장 추정·세액 계산의 처리시간 개선율이나 운영 SLA가 아니다. 운영 서비스에 Jev를 배포한 결과도 아니다.

## 배경과 비교 조건

상품 URL 분석에서는 상품의 기능·재질·구성에 따라 HS 후보를 좁혀야 한다. 문장을 생성해 구조화 값으로 변환하는 LLM과, 미리 정의된 후보의 선택·확률을 반환하는 Jev를 비교했다. Jev의 확률/형식 보장은 상품 분류 정답 보장과 다르다.

- 비교 모델: Jev `jev-1.13.0`, OpenAI `gpt-6-luna`, reasoning `low`.
- 동일 상품 텍스트와 공식 HS2022 taxonomy에서 **greedy 2→4→6자리**를 순차 선택. 정답을 입력에 넣거나 gold를 기준으로 후보를 제한하지 않았다.
- HF: HSCodeComp 전체632개 중32개 대분류에서 최대3개씩 사전에 선택한94개 층화 starter. 전체632개 결과가 아니다.
- Mercari:2026-10-06 공개 화면에서 수집한 실제 판매글30개 전체. 설명은 최대800자 발췌이며 사진은 분석하지 않았다.
- 각 상품에서 두 공급사를 동시 실행하며 공급사 내부 단계는 순차 실행. 시간은 실제 HTTP+응답 파싱/검증 시간 합의 중앙값이며 큐·수집·로컬 재표시 시간은 제외했다.
- 검색·선례·HS 해설서·이미지·복수 경로 탐색을 사용하지 않았다. 현재 운영 classifier의 복수 후보·부모 재검토까지 재현한 비교는 아니다.
- 자동 재시도 없음. 요청 전 예약·사용량·오류·캐시를 기록했다. 저장된 응답의 재표시는 추가 API 호출과 비용으로 세지 않았다.

Jev는 HF에서 중앙 처리시간6.4배, Mercari에서5.7배 빨랐다. 추정 비용은 각각57.0%,53.9% 낮았다. 공급사 tokenizer와 반환 정보량이 다르므로 토큰 수 자체가 동일한 작업량 단위는 아니다. Jev 출력 토큰은 무료이며 LLM 출력에는 내부 reasoning이 포함된다.

비용은 API usage와2026-10-06 공급사 단가로 계산했다. OpenAI의 캐시 read/write 단가를 적용했다. 청구서 확정액·세금·프로젝트 전체 지출과 구분한다. 아래 독립 심사를 포함한 총액은 약$0.410, 실제 API 요청은802회다.

## 품질을 구분해서 평가

| 평가 기준 | Jev | GPT-6 Luna |
|---|---:|---:|
| HF 전문가 참조 라벨 · 전체94개 HS6 exact match |28/94,29.8%|36/94,38.3%|
| HF 답변한 사례만의 정확도 |28/81,34.6%|36/65,55.4%|
| HF HS6 답변률 |81/94,86.2%|65/94,69.1%|
| Mercari · 심사자가HS6를 정한25개와 코드 일치 |21/25,84.0%|19/25,76.0%|
| Mercari · 보류 포함30개 전체 판단 일치 |21/30,70.0%|23/30,76.7%|

HF의 보류·실패·누락은 전체 정확도에서 오답으로 센다. HF 라벨은 공개 벤치마크의 전문가 참조이며 미국10자리의 앞6자리를 사용했다. 한국 HSK10자리 정답이나 공식 세관 결정문과의 대조가 아니다.

Mercari에는 공식 정답이 없다. 상위 모델 `gpt-6-sol` low가 **기존 예측과 공급사 이름을 보지 않고** 같은 전체 taxonomy를 이용해 독립 분류했다. 코드 일치율은 심사 모델 기준 대리 지표이며 정답 정확도가 아니다. 같은 OpenAI 모델군의 공유 편향 가능성도 남는다. 심사자는25개에HS6를 선택하고5개를 보류했다. Luna는 심사자의 보류5개 중4개에서 같은 보류 판단을 했고 Jev는0개였다. 독립 심사의 추정 비용은$0.308996로 별도 기록했다.

## 해석과 도입 방향

좁은 조건의 비정형 상품 표본에서 상위 모델과의HS6 일치율84%를 기록하면서 처리시간을 낮출 수 있었다. **모든 조건에서 같은 성능을 유지했다는 결과는 아니다.** HF에서는 Jev의 전체 정확도가 Luna보다8.5%p 낮았고 두 모델 모두 개선 여지가 크다. 상위 경로 오분류를 되돌리지 않는 greedy 구성도 최종 정확도를 제한할 수 있다.

도입 방향은 빠른 초기 후보·경로 판단과 불확실성 신호를 활용하고, 근거 부족·경쟁 후보·최종 분류를 추가 조사 또는 검토에 연결하는 것이다. 이는 실험에 따른 제안이며 구현·운영 효과까지 검증한 결과가 아니다. 세율은 모델이 생성하지 않고 공식 조회와 결정적 계산의 경계를 유지한다.
