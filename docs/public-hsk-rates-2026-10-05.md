# 공개 HSK 세율 조회와 계산 연결

## 출처와 처리

관세법령정보포털의 로그인 없는 공개 조회 화면이 사용하는 읽기 요청을 연결했다. 인증키가 필요한 OpenAPI를 사용하는 것은 아니다. 공개 응답에 포함된 화면/계정 관련 부가 필드는 버리고 품목·세율·단위당 금액·적용기간만 저장한다.

- [관세이력 조회](https://unipass.customs.go.kr/clip/hsinfosrch/openULS0401009Q.do)
- [한국 관세율표](https://unipass.customs.go.kr/clip/hsinfosrch/openULS0201002Q.do)
- [세율 적용 우선순위](https://unipass.customs.go.kr/clip/hsinfosrch/openULS0201009Q.do)
- [일반 부가세율: 부가가치세법 제30조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1031738785)

HS6 후보 → 해당 연도 한국 HSK 목록/상위 품명 → HSK 후보 선택 → 기본·조건부 세율 및 내국세 표시 확인 → 적용기간/계산 범위 검사 → 기본세율 시나리오 계산으로 연결한다.

HSK가 하나면 해당 후보에 연결한다. 여러 개면 LLM에는 세율을 제외한 공식 코드·전체 품명 경로와 상품 원문/추가 단서만 전달한다. 가장 낮은 세율을 고르는 방식은 사용하지 않는다. 모델은 목록에 없는 코드를 만들거나 입력에 없는 근거를 제시할 수 없도록 검증한다.

## 계산 범위

공개 기본세율 코드 A가 하나이고, 종가율이 유효하며, 단위당/선택 세액이 없고, 내국세 행에 명시적으로 별도 항목이 없을 때 검토된 일반 완제품 범위에 한해 기본관세 + 일반 부가세 10% 시나리오를 계산한다.

일반 시나리오 범위는 HS 류 39·40·42·48·61~66·69·70·73·74·76·82~85·94~96이며 9619는 별도 검토한다. 42/94류의 고가 조건은 200만원 기준 추가 검토로 보수적으로 중단한다. 추가 내국세 표시가 있으면 이 일반 경로로 계산하지 않는다. 이는 부가세 면제/개별 감면·모든 추가 세목의 자동 판정이 아니며 실제 적용 세율이나 수입 허가를 확정하지 않는다. 기존의 검증된 주류 등 계산 프로필 경로는 유지한다.

덤핑·상계·보복·긴급·특별긴급·조정 세율이나 기본세율보다 높은 다른 세율이 발견되면 적용조건 검토로 보류한다. WTO·FTA·잠정·탄력 등 다른 세율은 별도 표시하고 자동 적용하지 않는다. 일본 판매처라는 사실을 일본산 원산지 증명으로 취급하지 않는다. 기본세율 시나리오는 실제로 우선 적용되는 양허/협정세율보다 높을 수 있다. 미확인 비용과 조건은 부분 견적으로 표시한다.

## 데이터·안정성

- 별도 `hsk_tariff_cache` 테이블에 버전·기준일·출처·조회 시각·적용기간을 저장한다(009 마이그레이션).
- 6시간 캐시 및 DB 잠금으로 동시 중복 조회를 합친다. 실패 시 만료된 자료로 계산하지 않는다.
- 페이지 수·HS 접두어·HTML 계층 누락·상세 화면 HS 불일치·날짜·세율 형식 등을 검사한다. 최대 10페이지/100건씩이며 초과/누락은 보류한다.
- 여러 HSK 중 최대 3개 계산 후보를 사용하며 미계산 후보가 있으면 완전한 상한으로 제시하지 않는다.
- 날짜/6시간 창과 계산 버전을 자동 작업 키에 포함하여 이전 결과가 무기한 재사용되지 않게 했다.
- 소수점 관세율은 고정소수점으로 계산한다. 누락 세율을 0으로 변환하지 않는다.
- 공개 HSK 코드/기본세율/조건부 세율/조회일을 하단 관세 상세에 표시한다.

## 표본 확인

`9504400000 오락용 카드`의 2026년 공개 자료에서 기본 A=8%, WTO C=0%를 확인했다. 기본세율 계산 경로는 A=8%를 사용하고 C=0%는 적용조건 미확인 정보로 분리한다. 35개 원자료 중 확인일에 유효한 항목은 33개였다. 오래된 협정문서의 기준세율을 현행 기본세율로 가져오지 않았다.

단순 테스트 입력 과세가격 1,000,000원에서 A=8% 기본관세 80,000원 + 부가세 108,000원 = 188,000원 시나리오를 검증했다. 실제 상품의 적용 세액 정답과 대조한 결과는 아니다.
