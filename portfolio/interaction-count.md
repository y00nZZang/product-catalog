# 플러그인 시험의 사용자 메시지 수

2026-10-05 라쿠텐 북스 구매·몰테일 배송대행 접수 실험. 2026-10-06에 전체 대화의 사용자 메시지와 접수 기록을 대조했다. 개인 주문 식별자·계정 정보·브라우저 자동 첨부 정보는 공개하지 않는다.

**첫 요청 1회 + 후속 입력 6회 = 사용자 메시지 총 7회**로 주문 확인과 배송대행 접수까지 진행했다.

| 순서 | 사용자가 전달한 내용 | 구분 |
|---|---|---|
| 1 | 상품 URL, 한국 구매·배송대행 등록 요청, 인증 직접 수행 및 결제 전 확인 조건 | 최초 요청 |
| 2 | 라쿠텐 로그인 완료 알림 | 로그인 완료 |
| 3 | 몰테일 로그인 완료 알림 | 로그인 완료 |
| 4 | 이름·주소 입력 승인, 구매 확정 전 알림 요청, 무게 최대 약200g 가정 추가 | 입력 승인·조건 보완 |
| 5 | 직접 최종 구매를 확정했다는 알림 | 구매 완료 |
| 6 | 저장 수령정보·필수 동의 안내 후 진행 승인 | 제출 승인 |
| 7 | 통관부호 인증 완료 알림 | 인증 완료 |

후속 입력은 로그인 완료2회, 입력·제출 승인2회, 구매·인증 완료 알림2회다. 네 번째 메시지의 무게 가정과 요청 보완도 같은 메시지1회에 포함한다. 접수 완료를 확인한 에이전트의 마지막 응답까지를 집계했다. 도구 호출·진행 설명·브라우저 자동 첨부 상태는 사용자 메시지로 세지 않는다.

## 이 수치가 보여주는 것

사용자는 상품 URL과 목적을 전달하고 후속 확인·승인·완료 알림을 보냈다. 에이전트가 상품과 배송대행지를 조사하고, 배송지·주문 정보를 옮겨 입력하고, 주문·신청 접수 결과를 대조했다. 세부 폼의 각 필드를 사용자에게 일일이 요청한 방식은 아니었다.

## 집계 범위

- ‘7번의 클릭’이나 ‘7개의 입력 필드’가 아니다. 로그인·직접 구매·통관 인증을 위한 실제 화면 조작과 타이핑 횟수는 측정하지 않았다.
- 이미 생성된 계정, 저장된 수령정보, 장바구니 상품1개가 있는 상태였다. 계정 신규 가입부터 시작한 전체 입력량이 아니다.
- 단일 사례이며 수동 진행과의 대조군·반복 표본이 없어 시간 절감률이나 입력 감소율로 환산하지 않는다.
- 배송대행 신청 접수까지의 결과다. 발송 후 운송장 보완, 국제배송비 결제와 수령은 이 범위 밖이다.
- 과거 실험 대화 전체의 사용자 메시지7건과 동일 실험의 진행·완료 기록을 직접 대조했다. 민감한 원본 대화 전체는 공개하지 않는다.
