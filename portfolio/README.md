# 구매대행 제품 실험 — 윤장한

## 프로젝트 목적

AI가 구매대행의 어떤 업무를 보조할 수 있고, 사업자에게 어떤 역할이 남는지 직접 구매 과정으로 탐색했습니다. 기능 목록보다 구매 전 비용의 불확실성, 사이트 간 반복 입력, 인증과 결과 확인에서 출발했습니다.

## 두 가지 구현

1. **Crossborder Purchase Agent** — Codex skills 5개와 Python·SQLite helper. 상품 조사와 견적 비교, 승인 조건·실행 상태 기록, 라쿠텐 주문 대조와 몰테일 신청을 연결합니다.
2. **Product Catalog** — NestJS·PostgreSQL·독립 워커. URL 수집, 이미지·검색 기반 포장 추정, 공개 세율 기반 관세 시나리오를 제공하는 배포 서비스입니다. 두 제품은 아직 자동 API 연동되지 않았습니다.

## 확인한 결과

- 단일 실제 구매에서 사용자가 최종 주문을 확정하고 에이전트가 몰테일 접수를 완료했습니다. 주문 합계 5,616엔, 국제운임·수령은 미확인입니다.
- 구매대행 오프라인25개, 분석기 회귀298개·DB통합17개 테스트를 통과했습니다. 실측 예측 정확도나 운영 SLA를 의미하지 않습니다.
- 분석기 실제 카드 사례에서 HS→HSK→공개 기본세율과 예상 세금 계산을 연결했습니다. FTA·WTO 조건을 임의 적용하지 않으며 미확인 비용을 남깁니다.

## 제품 판단

직접구매는 수수료만으로 선택할 수 없었습니다. 초기 견적에서도 모든 대행 경로보다 저렴하지 않았고, 인증과 사후 물류는 입력 자동화로 사라지지 않았습니다. 그래서 URL 입력을 최소화하면서도 확인 비용·추정 근거·남은 조건을 함께 보여주도록 설계했습니다.

물류·검수·보상·예외 대응이 사업자의 차별점으로 남을 수 있다는 것은 후속 가설입니다. 계약 운임·내부 원가·반복 표본이 없어 시장 대체 효과나 절감률은 주장하지 않습니다.
